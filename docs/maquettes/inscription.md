# Écran d’inscription — ZakFit

## Éléments à afficher

- Titre « Créer un compte »
- Champs « Nom » et « Adresse e-mail »
- Champs « Mot de passe » et « Confirmer le mot de passe », avec texte masqué
- Bouton principal « Créer mon compte »
- Lien « J’ai déjà un compte » vers la connexion

## États à maqueter

- Formulaire initial avec les champs vides.
- Mots de passe différents, avec un message sous le champ de confirmation.
- Envoi en cours, avec le bouton temporairement désactivé.
- Erreur si l’adresse e-mail est déjà utilisée ou si le serveur est inaccessible.
- Confirmation « Compte créé. Vous pouvez vous connecter. »

## Navigation

Une fois le compte créé, l’utilisateur revient à l’écran de connexion.
